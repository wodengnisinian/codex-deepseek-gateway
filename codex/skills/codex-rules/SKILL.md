# Codex 使用规则

## 核心原则
1. **优先使用项目配置** — 优先使用本项目的 `codex/config.toml`，不要覆盖或修改 `.codex/config.toml` 中的网关相关配置
2. **禁止输出思考过程** — 在与用户交互时，不输出内部推理或思考过程
3. **模型选择** — 默认使用 `deepseek-v4-flash`，仅在用户明确要求时切换模型
4. **本地优先** — 所有 API 请求优先走本地网关 `http://127.0.0.1:3688/v1`

## 文件操作
- 修改 `.codex/` 目录下的文件前，先确认是否通过本项目的 `apply_codex_all.ps1` 脚本来同步
- `.env` 文件包含敏感信息，不要提交到 Git
